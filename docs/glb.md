# 対応するGLBと、対応しないもの

自己完結した GLB だけを読みます（STL は [stl.md](stl.md)）。判定は拡張子ではなく、先頭4バイトが `glTF` であることです。形状は BIN チャンクから読みます。`uri` があるバッファ（data: を含む）は読みません。

三角形リストを読みます。ストリップとファンはリストへ直します。既定のシーンが無ければ先頭のシーン、シーンが無ければ親の無いノードを根にします。カメラとライトのデータは読まず、警告も出しません。

失敗してもアプリは動き続けます。転送が終わるまで、開いていたモデルは置き換わりません。

## 理由を出して開かないもの

| 条件 | 表示 |
|---|---|
| 先頭が glTF でない | GLBではありません |
| 必須拡張 `KHR_draco_mesh_compression` または `EXT_meshopt_compression` | 必須拡張 {名前} は未対応です（形状が圧縮されているため未対応） |
| 必須拡張 `KHR_mesh_quantization` | 必須拡張 {名前} は未対応です（量子化された頂点形式は未対応） |
| 必須拡張 `EXT_mesh_gpu_instancing` | 必須拡張 {名前} は未対応です（拡張によるインスタンス配置は未対応） |
| 上以外の未知の必須拡張 | 必須拡張 {名前} は未対応です（未知の必須拡張） |
| バッファに uri がある | 外部バッファは未対応です |
| BIN が無いのにバッファを参照する | BINチャンクがありません |
| 範囲、型、個数、ノード参照、範囲外のインデックス、非数の位置など | データが破損しています（{箇所}） |
| sparse アクセサ | 未対応の形式です（sparse アクセサ） |
| 親が2つ、循環、シーンの根が不正 | ノード階層が不正です: {詳細} |
| 描けるメッシュが無い | 表示できる形状がありません |
| 頂点やインスタンスが u32 を超える | 大きすぎます（{何が}） |

必須でも受け入れ、警告にする拡張は次です。`KHR_materials_unlit`、`KHR_materials_emissive_strength`、`KHR_materials_ior`、`KHR_materials_transmission`、`KHR_texture_transform`、`KHR_lights_punctual`。

任意の Draco や meshopt は、代替のアクセサがあればそれを読みます。無ければ破損として扱います。

## 開いて簡略表示にするもの

状態欄に「簡略表示 N 件」と出ます。押すと一覧が開きます。

| 内容 | 表示 |
|---|---|
| テクスチャ | テクスチャ N 件は読まず、色は baseColorFactor だけで表示します |
| 頂点色 | 頂点色 N 件は読まず、色は baseColorFactor だけで表示します |
| アルファ合成 | アルファ合成 N 件は読まず、色は baseColorFactor だけで表示します |
| アニメーション | アニメーション N 件は再生せず、静止した姿で表示します |
| スキン | スキン N 件は再生せず、静止した姿で表示します |
| モーフ | モーフ N 件は再生せず、静止した姿で表示します |
| 法線が無い、または法線が壊れている | 法線の無い形状 N 件は、面ごとの法線で表示します |
| 線と点 | 線 N 個、点 N 個を省略しました |
| 上の許可リストの拡張 | 拡張 {名前} は見た目だけを簡略化して表示します |
| 知らない任意拡張 | 未対応の任意拡張 {名前} は無視します |

## 書き出し

「書き出し」は、開いたGLBを土台にして、変えた所だけを直した新しいGLBを書きます。元のファイルは書き換えません。

- **保つもの**: テクスチャ、材質、アニメーション、スキン、モーフ、カメラ、知らない拡張、`extras`、元のBINのバイト列。既存の要素の番号は1つも変えず、足す物は配列とBINの末尾に付けます。JSONは値として保ちます。項目の並びと数の書き方（`1.0` と `1.0e0` など）は変わることがあります。
- **変えるもの**: 動かした部品の変形（位置・回転・大きさの3項目。傾いた拡大は `matrix`）、子の並びが変わった親の `children`、根が変わったときのシーンの `nodes`、`buffers[0].byteLength`。
- **複製**: 元のノードを写して名前・子・変形だけを差し替えます。同じメッシュを指すので、テクスチャつきの形もそのまま使われます。
- **足した図形**: メッシュ・アクセサ・バッファビュー・材質（基本色のみ）を末尾に足します。

**削除した部品は、シーンから外すだけです。ノードと形状のデータはファイルに残ります。** 番号を詰めると、本アプリが中身を知らない拡張が指す番号を直せないためです。受け取った人がデータを取り出せるので、見せたくない形を消したいときは別のソフトで取り除いてください。書き出しの結果に、外した部品の数を必ず出します。

結果の一覧には、ほかに次を出します。アニメーションの対象になっている部品を動かした数（再生するソフトではアニメーションの値が優先されます）、スキンの付いた部品を動かした数（glTF の決まりで表示に使われません）、`matrix` で書いた部品の数、シーンが無いファイルにシーンを足したこと。

書き出さないとき（理由を出し、保存先には何も残しません）:

- 保存先が「開く」で開いたファイルと同じ（別名のリンク経由も含む）。同じ作業の中で書き出したファイルへは書き直せます。
- 元のファイルが開いたときから変わっている、または見つからない。
- 全体が4GiBを超える。
- 書いた結果を読み直した照合（元のBINの一致、変えていない項目の一致、部品の数・名前・位置・三角形の数）に通らない。

書き出した後は、作業の対象が新しいファイルに移ります。レビューは新しいファイルに結び付いて保存されます。取り消しで書き出した時点まで戻ると「形の編集 未書き出し」の印が消えます。
