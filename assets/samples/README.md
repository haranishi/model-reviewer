# 確認用サンプル

`review-sample.glb` は、このリポジトリのテストデータ生成器が作る自作の手押し車です。外部のモデルやスキャンデータは使っていません。

ライセンスはリポジトリと同じ MIT OR Apache-2.0 です。

生成コマンド:

```
cargo run -p model-reviewer-testdata -- sample assets/samples/review-sample.glb
```

組み立て全体（`assembly`）は高さ方向に 0.57 持ち上げてあり、車輪の下端がちょうど床（高さ 0）に載ります。床の格子が車輪に重なって透けないようにするためです。

ノードは 12、メッシュは 6、ユニークな三角形は 140、置いた三角形は 524 です。回転は角度からその場で計算せず、ソースに書いた四元数の定数をそのまま入れます。円柱は24分割で、頂点も定数です。`sin` / `cos` の最下位ビットが OS で食い違っても、置いたファイルと生成結果は構造が一致し、数値の差が 1e-6 以内なら同じとみなします。同じ環境で 2 回生成したバイト列は一致します。
