# Model Reviewer 0.1.0

Open a GLB or STL, move parts, measure distances and export an edited GLB. The interface is in Japanese.

| Download | Platform |
|---|---|
| `model-reviewer-0.1.0-macos-universal.zip` | Apple Silicon and Intel, built for macOS 11 or later (tried only on a recent macOS on Apple Silicon) |
| `model-reviewer-0.1.0-windows-x86_64.zip` | Windows x86-64, experimental |
| `model-reviewer-0.1.0-linux-x86_64.tar.gz` | Linux x86-64, built on Ubuntu 22.04, experimental |

Compare the archive's SHA-256 with its entry in `SHA256SUMS`. Extract the archive and read `START-HERE.txt` for first-launch instructions, including how to open the unnotarized Mac app or the unsigned Windows executable. Each archive includes a sample cart and box, the project licenses and the third-party notices.

ソースからビルドした版の画面は Apple Silicon の Mac で確認しています。Windows と Linux は実機の画面が未確認の試験版です。「開く」から `samples/review-sample.glb` を選ぶと、台車の見本で操作を試せます。
