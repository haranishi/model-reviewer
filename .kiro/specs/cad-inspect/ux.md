# UX設計（ユーザーストーリーとUX5階層）

実装の前に書いた。戦略から順に決め、下の階層の判断は上から導いている。第1段階と第2段階の ux.md（[初版](../model-reviewer/ux.md)、[編集の土台](../editor-foundation/ux.md)）はそのまま有効で、ここには足す分だけを書く。

## 誰のためか
- **使う人**: 設計データ（部品の STL、建物や装置の GLB）を受け取り、「図面どおりの寸法か」「中はどうなっているか」を確かめる人。CAD は持っていないか、開くほどの用ではない。測った結果を指摘として返す。
- **救う相手**: データを作った人。「ここが 0.5 mm 足りない」と場所と数値で言われれば直せる。「なんとなく小さい」では直せない。

## ユーザーストーリー
| # | 欲しいことと理由 | 受け入れ条件 |
|---|---|---|
| C1 | 角から角までを測りたい。面の上を目分量で押すと、毎回違う値になる | ポインタを角に近づけると印が角に付き、押すとその角が計測の点になる |
| C2 | いま何に吸い付いたのかを知りたい。違う物に付いたまま測ると、誤った数値を信じてしまう | 頂点・辺・面で印の形と言葉が違う。置いた後も、2点それぞれの種類が残る |
| C3 | 幅だけ、高さだけを知りたい。斜めの距離では図面と比べられない | 距離と一緒に X・Y・Z ごとの差が出る |
| C4 | 中の厚みやすき間を見たい | 1回押すと切れて中が見える。位置を動かしながら見られる。切った所に吸い付いて測れる |
| C5 | STL を変換せずに開きたい | 「開く」で開ける。壊れたファイルは理由が出て、アプリは落ちない |
| C6 | 数値を mm で読みたい。STL には単位が無いので、何と仮定したのかも知りたい | STL は mm と仮定して開き、状態欄に仮定が出る。違えば1回で変えられる |
| C7 | 「ここに 20×30×40 の物が入るか」を、形を置いて確かめたい | 図形を置き、寸法を mm で打つと、その大きさになる |
| C8 | 選んだ部品の大きさをすぐ知りたい | 部品を選ぶと、外形の幅・高さ・奥行が出る |

## 1. 戦略
- 目的は「受け取ったデータの寸法を、信じられる数値で確かめられるようにする」。形を作る道具にはしない。
- 大事にする順番は、①数値の出どころを偽らない（何に吸着したか、単位は何を前提にしたか）、②利用者のファイルと指摘を失わない・壊さない（第2段階のまま）、③いまの状態が見える、④トラックパッドだけで迷わない、⑤待たせない。
- 計測を使わない人の画面を重くしない。足した部品は、使う道具を選んだときだけ出す。

## 2. 要件（戦略から導いたもの）
- ①から: 吸着の種類を形と言葉で出す。平らな面の対角線には吸着しない。単位は「ファイルの単位（前提）」と「表示の単位」に分け、STL の仮定を常に出す。親の中の座標である「変形」の位置には単位を付けない。切り口は本物のふたではないので、ふたに見える塗り方をしない旨を書く。
- ②から: STL も書き換えない。STL の単位の仮定を変えるのは開き直しなので、未保存があれば確認する。断面は保存されないので、未保存の印に入れない。
- ③から: 断面の軸・位置・向きは、切っている間ずっと3Dビューの上端に出す。平面の枠を3Dの中に出す。消えた側の注釈は薄くして残す。
- ④から: 吸着は既定で入、キー X で切り替え。断面の位置は矢印のドラッグ。どれも左ボタンだけで済む。
- ⑤から: 吸着の探索はポインタが動いたフレームだけ。重ければ自分で間引く。断面は定数1つの更新で済ませる。

## 3. 構造
- 画面は1枚のまま。道具も増やさない（計測の道具が吸着を持ち、図形の道具が寸法を持つ）。断面は道具ではなく、表示の切り替えの仲間にする（どの道具とも同時に使える）。
- 右のパネルは「モデルの数値」を集める場所にする。上から 部品 → 変形 → 寸法 → 計測。寸法は部品を選んでいるとき、計測は計測の道具のときだけ中身を出す。
- 単位は状態欄の2つの部品で扱う。左が前提（GLB は「1単位 = m」、STL は「STL = mm（仮定）」）、右が表示（「表示 mm」）。
- 断面で消えた側は「無いもの」として扱う（当たらない、吸着しない）。ただし利用者が置いた物（注釈、計測）は消さずに薄く残す。

## 4. 骨格
```
┌ [開く] │ [レビュー保存][レビュー読込] │ [書き出し] │ [戻す][やり直す] │ [全体表示]… │ [注釈を追加] │ [?] ┐
├─────────────┬───────────────────────────────────────────────────────┬───────────────┤
│ 注釈・視点  │┌──┐   [面|面と線|線|透かし] [透視|平行] [格子] [断面]  ┌────┐│ 部品（一覧）  │
│             ││選│   [X|Y|Z] 位置 [ 12.50 mm ] [反転]  ← 断面が入のとき └────┘│ ───────────── │
│             ││移│                                                      │ 変形          │
│             ││…│        3Dビュー   ┌╌╌╌╌╌╌╌╌┐ 平面の枠               │ 位置 回転 大きさ│
│             ││計│[吸着 入] ← 計測    ╎   ◀━▶  ╎ 矢印（ドラッグ）       │ ───────────── │
│             ││  │        の道具のとき └╌╌╌╌╌╌╌╌┘                        │ 寸法          │
│             │└──┘           □頂点  ◇辺  ○面  ← 候補の印と言葉          │ 幅X 高さY 奥行Z│
│             │                                                       │ ───────────── │
│             │                                                       │ 計測          │
│             │                                                       │ 距離 ΔX ΔY ΔZ │
├─────────────┴───────────────────────────────────────────────────────┴───────────────┤
│ a.stl │ 計測: もう1点をクリック │ arm │ STL = mm（仮定） │ 表示 mm │ 格子 10 mm │ 部品 1 │ [詳細▴] │
└─────────────────────────────────────────────────────────────────────────────────────┘
```
- [断面] は上端の表示のボタンの並びの右端に足す。入のとき、すぐ下にもう1行（軸・位置・反転）を出す。切にすると行ごと消える。
- [吸着 入／切] は、図形のボタンと同じ場所（道具の列の横）に、計測の道具のときだけ出す。
- 候補の印は、ポインタではなく候補の点に描く。脇に「頂点」「辺」「面」と書く。辺は、辺の線全体を太くなぞる。
- 平面の枠は細い破線の長方形。中央に、軸の向きの両矢印（当たりの幅12ポイント）。枠は部品に隠れない（前後関係を付けない）。
- 「寸法」は、読み込んだ部品では外形の3つの数値と1行の説明、足した図形では直せる欄。「計測」は、距離・3つの差・2点の種類。
- 幅960では、状態欄の「格子」を先に省く（省く順は [design.md](design.md) の「画面」）。

## 操作表（第2段階の表に足す分。ヘルプにも同じ表を出す）
| したいこと | マウス・トラックパッド | キー |
|---|---|---|
| 角や辺に合わせて測る | 「計測」→ 印が付いた所でクリック | M |
| 吸着を入れる・切る | 道具の列の横の [吸着] | X |
| 切って中を見る | 上端の [断面] | C |
| 切る軸を選ぶ・向きを反転する | 断面の行の [X][Y][Z]、[反転] | |
| 切る位置を動かす | 3Dビューの矢印をドラッグ、または位置の欄を左右にドラッグ・数値を入力 | Enter で確定、Esc で戻す |
| 図形の寸法を決める | 「図形」で置く → 右の「寸法」に入力 | Enter で確定、Esc で戻す |
| 表示の単位を替える | 状態欄の「表示 …」を押す（ファイルと同じ → mm → cm → m） | |
| ファイルの単位の前提を替える | 状態欄の「1単位 = …」「STL = …」を押す | |
X と C は修飾キーなしの1文字。Cmd+X・Cmd+C は切り取りとコピーに使われるので、割り当てない。

## 5. 表層
配色と文字は第2段階のまま。足す色は2つ。切り口は橙 #D9822B（照明なし）、吸着の印と平面の枠は琥珀（選ばれた道具と同じ色）に暗い縁。印は図形で描き、絵文字に頼らない。薄く描く物（消えた側の注釈と計測）は不透明度40%。

## この検討で要件・設計が変わった点: 9件
依頼の4項目をそのまま実装した場合からの変更。
1. **吸着した種類を、置いた後も残す**（C2、戦略①）。印は置く前だけでなく、計測のパネルに2点それぞれの種類を出す。`Measurement` に種類を持たせた。
2. **平らな面の対角線に吸着しない**（戦略①）。辺の定義を「面の境目か縁」にし、隣の三角形を調べる処理を足した（要件1.4）。
3. **単位を「前提」と「表示」に分けた**（C6、戦略①）。換算は表示を選んだときだけ行い、既定では第2段階と同じ数値になる（要件7.1〜7.3）。
4. **「変形」の位置には単位を付けない**（戦略①）。親に拡大がある部品で、誤った単位つきの数値を出さないため（要件7.4）。
5. **STL の単位の変更を、開き直しにした**（戦略②）。部品の大きさを書き換える編集にすると、取り消しと状態欄の表示がずれる（要件7.7）。
6. **断面を道具にせず、表示の切り替えにした**（構造）。計測の道具のまま切って、切り口の角を測れる。
7. **切り口にふたをしない代わりに、制限を画面と文書に書く**（戦略①）。ふたに見える絵を、正しくない形状にも出すことを避けた（要件3.5）。
8. **消えた側の注釈と計測は消さず、薄く残して押せなくする**（構造、戦略②）。利用者が置いた物を、断面のせいで見失わせない（要件4.3）。
9. **図形は置いてから寸法を打つ**（C7、戦略④）。置く前に寸法を聞く小窓を作らず、第2段階の「押すとすぐ置かれる」を保ち、寸法は右のパネルの欄にした（要件9.1）。
