# 元のモデルとレビューを守る

1. この起動で開いた GLB・STL は、別名にしたり別のドライブへ移したりしても、レビュー保存と GLB 書き出しで置き換えない。開いたパスとそのリンクも保護する。アプリが書いた GLB は同じ場所に再出力できる。
2. レビューの保存先には、新しい名前か、この版で読めるレビュー JSON を選べる。それ以外を選んだときは理由を示し、保存先と未保存の状態を保つ。
3. 表示モデルの置き換え中は、保存先の選択とレビューの書き込みを止める。レビュー復元のための読み直しも含む。
4. 書き出し後の復元で別の候補を開いたら、そのモデルも保護する。現在の書き出し先を自動で読み直すときだけ、再出力を許す。
5. STL の単位や上の向きは、開いたときと同じ内容を読み込めた場合だけ切り替える。内容が変わっていたときは理由を示し、元のモデル、単位、上の向き、注釈、形の編集を保つ。
6. 次の読み込みが失敗または取り消しになっても、表示中のモデルで選択と注釈を続けられる。
7. 同じ STL を改名して指定したときも注釈と非表示を復元する。単位の記録がなければ mm、上の向きの記録がなければ Y を使う。GLB は引き続き部品名も照合する。
