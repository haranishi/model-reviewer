# 検証の記録（STL の上の向き。2026-11-27、macOS 27.2.1・Apple M4 Pro）

元ファイル保護（[protect-originals](../protect-originals/verification.md)）と、画面を出さない自動操作を重ねた版で確かめた。

## 検査
| 検査 | 結果 |
|---|---|
| `cargo fmt --all --check`・`cargo clippy -D warnings`・`cargo build --release` | 成功 |
| `cargo test --workspace -- --include-ignored`（別のソフトで作った STL 4つを含む） | 755件成功、失敗0 |
| `cargo deny check licenses sources bans`・Rust 1.95 の `cargo check` | 成功 |
| 自動操作31本（`stl-3` を追加。画面は透明で、前面のアプリは変わらない） | 成功。見本の GLB と STL のハッシュは同じ。利用者の設定の場所は作られない |
| 実物のアプリでの保護（開いた写しを内蔵ディスクへ移し、移した先へ書き出し・保存） | 断られ、中身は変わらない。同じ出力先への書き直しは成功 |

## 画面と書き出し
- 見本の箱を開くと、寸法は幅20・高さ40・奥行30 mm、回転 X は -90°、状態欄は「上 = Z（仮定）」。
- 手順書 03 の計測の2点を取り直し（どちらも「頂点」、距離 20.00 mm）、03・05 の絵を撮り直して目で確かめた。
- 別の3Dソフト（Blender 5.2.2 LTS）で、Z が上で書き出した GLB の範囲は元の STL の座標と同じ（0.020×0.030×0.040 m）。Y が上で書き出した GLB は、ファイルの Y が上になる。

## 公開の順に合わせて直した点
- STL を Y が上で表示する版を先に公開したので、`stl_up` の無いレビューは Y が上として読むことにした（初めの案は Z）。

## レビュー
- 実装とは別の担当（別のセッション）が読み、12件を指摘した。公開中の版にも及ぶ保存・復元の問題は protect-originals で直した。この仕様の5件（古い版での再保存の説明、書き出し結果の文、長い名前の状態欄、土台の回転を直接確かめる試験、STL のレビューを別の起動で戻す手順）を直し、試験を壊して落ちることも確かめた。
- 極端に薄い形で、四元数の丸めにより 0.001 mm 未満の端数が出る指摘は、許容差の内なので直さない（design.md）。
