# 10　困ったとき

部品や編集が見えなくなったら、まず状態欄のファイル名を確かめます。開き直す前に「形の編集 未書き出し」や「レビュー未保存」が出ていれば、作業を残せます。

1. 画面下の知らせや、開いている小窓の理由を読みます。押せないボタンは、ポインタを載せると理由が出る場合があります。
2. 次の表でいまの症状を探します。詳しい操作はその行の手順を開いてください。

## 画面の症状から探す

| 症状 | 確かめること・対処 |
|---|---|
| 起動しない | 端末で起動したときの文を読みます。「起動できませんでした」と出たら GPU と画面が使える環境か確認します。ビルドする場所はソースの `Cargo.toml` があるフォルダです。[01 起動](01-start.md) |
| 日本語の文字が四角になる | アプリは OS のフォントを使います。日本語フォントを入れてから起動し直します。 |
| モデルを開けない | 「読み込めません」の理由を読みます。まず付属の見本を開き、開けたら手元のファイルが対応する形式か確かめます。[GLB](../glb.md)・[STL](../stl.md) |
| キーが効かない | 入力中の欄を離れ、開いている確認・ヘルプ・設定を閉じます。ポインタは一覧の上でもかまいません。軸の数値入力中なら Enter で確定するか Esc でやめます。「ショートカットの設定」で今の割り当ても確認できます。[09 キーの設定](09-shortcuts.md) |
| X や Z で「吸着」や「面と線」が切り替わらない | 「移動」「回転」「拡大」で部品を選ぶと、X・Y・Z は向きの固定に使われます。「吸着」は「計測」に替えて操作し、表示を変えるには上端の「面と線」を押します。[11 キーで動かす](11-create.md) |
| 長さの数値が1000倍違う | 1 m と 1000 mm は同じ長さです。GLB は「1単位 = m」、STL は「STL = mm（仮定）」のボタンで、前提を作成時の単位に合わせます。STL は仮定を替えると開き直します。同じ長さを別の単位で読むには「表示」の単位を替えます。[05 STL の寸法](05-stl.md) |
| 状態欄に「表示」や「格子」の値が見えない | ウィンドウを広げます。「格子」の間隔を見るには、3Dビュー上端の「格子」も入れてください。 |
| キー設定が次の起動で戻る | 設定の「探す」の横と状態欄で理由を読みます。読み書きできないと出たら、保存先フォルダの権限を確認します。「新しい版の設定」なら、設定を作った版のアプリで開きます。保存に失敗しても、その起動中は変更したキーを使えます。[09 設定ファイルの場所](09-shortcuts.md) |
| 終了時に未保存の確認が出ない | macOS の Dock の「終了」やログアウトでは確認が出ません。作業中は「書き出し」と「レビュー保存」を済ませてからウィンドウの閉じるボタンを使います。[01 終了](01-start.md) |
| 色を変えたのに、ほかのソフトでは違う色に見える | 「色」の「今の色」が書き出す基本色です。選択中の部品は少し明るく表示されます。ほかのソフトではテクスチャ（表面の画像）や頂点の色が基本色に掛かります。ソフトごとの実際の見え方は未確認です。[11 色を付けて保存する](11-create.md) |

## 実際のキーボードでうまくいかないとき

数字は文字キーの段で試します。日本語入力中なら英数に切り替えてください。日本語配列の実キー、入力欄の外で日本語入力を入れたとき、テンキー、数字・小数点・負号・矢印の届き方、押し続けたときの動きは未確認です。F1 でヘルプを開けないときは上部の「?」から同じ操作表を開けます。
